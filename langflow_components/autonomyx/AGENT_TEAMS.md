# AgentNxt Custom Agent Teams

## Teams
- Integration Team: Jira/Asana/HRMS/SSO integration and import.
- Automation Team: Policy + process ingestion and orchestration generation.
- Build Team: Tools, skills, memory, and adapter assembly.
- Deploy Team: Publish, notify, channels, and rollout controls.

## Policy Upload Behavior
- When a policy is uploaded, default agents are marked archived in generated blueprint metadata.
- New policy-derived agent teams are produced from parsed policy rules.
